# Changelog

What changes in each version, newest first. The versions follow [semantic versioning](https://semver.org):

- **Patch** (`1.0.1`): bug fixes that change nothing else.
- **Minor** (`1.1.0`): new features that leave the old ones working as they did.
- **Major** (`2.0.0`): a change that could break someone who uses the project, such as an option removed or renamed. Say what to change.

Add a line under *Unreleased* in the pull request that makes the change. To release, rename *Unreleased* to the version and the date, `## 1.2.3 (YYYY-MM-DD)`, and add a new *Unreleased* above it. Each release is tagged `v1.2.3`.
